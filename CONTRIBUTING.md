# Contributing

Use ASD-STE100-style short, direct sentences. Use path tokens such as
`<OPERATOR_INSTALL>`. Do not publish user names or private drive paths.

Keep framework source map-neutral. Put a map ID, coordinate, terrain size,
shader repair, or navigation graph in the map package or companion repository.

For a source change, include the exact game build, interop source, static
check, and physical runtime test. Do not include extracted game assets or game
DLLs in a commit.
